    Before you begin

    Three quick questions to help us route your request to the right teams. This takes under a minute.

    1
    Eligibility check
    Step 1 of 2  ·  Step 2: Full request form
    Question 1
    Is this a desktop application that needs to be installed on a computer?
    A desktop application requires software to be downloaded and installed on a local computer before it can be used. Examples include standalone versions of Zoom, Adobe Acrobat, or Microsoft Office. Web-based tools that run entirely in a browser (like Google Docs or Miro) are not desktop applications.
    Question 2
    Will this application process or store sensitive data?
    Sensitive data includes: personal information covered by data protection regulations (names, email addresses, HR records, staff performance data); financial data; health data; or anything your organisation classifies as confidential. If you are unsure whether your use case involves sensitive data, answer Yes — the review team will confirm the classification.
    Question 3
    Is this application part of a business-critical process?
    Business-critical means your team's core work would be significantly disrupted if this application became unavailable, and there is no reasonable workaround. Examples: a CRM your team uses every day to manage client relationships; a compliance tool required for regulatory reporting. Applications used occasionally or for non-essential tasks are not business-critical.
