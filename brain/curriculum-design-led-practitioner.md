# Curriculum Context — Design-Led: Practitioner

Track: **Design-Led: Practitioner**. Source: `curriculum/design-led-practitioner/Design_Led_Practitioner_Full_Curriculum.pdf` (2026 Edition) and `business-planning/_dtd_curriculum_extract.txt` (the entry-point diagnostic). All content sourced directly.

**13 half-day modules.** Core claim: design is not a craft function, it's a thinking discipline — "the hybrid designer... is the role organisations need most right now." Program is about judgment: seeing clearly, deciding wisely, acting intentionally in complex systems full of humans, constraints, politics, and possibility.

**Entry point:** Design Thinking Diagnostic — a 20–30 minute AI-coached conversation, same Discovery→Meaning→Action→Integration architecture as the Why Workshop (see `frankly-human-loop.md`), but replacing every values-finding move with a pattern-naming one. Opens with the same "onboarding flow, on time, under budget, 34% worse drop-off" story Module 01 uses. Produces a **Design Influence Profile** — a specific named pattern (e.g. "Strong on craft, invisible at the strategy table"), not a category.

## The 13 modules

| # | Module | Core claim / opening story anchor |
|---|---|---|
| 01 | Foundations | Design is judgment, not decoration. Opens with Meridian Bank's onboarding flow (34% worse drop-off, nobody asked why). Introduces the **three lenses** (Desirable / Viable / Feasible) and **six design mindsets** (empathy first, systems thinking, bias to action, embrace ambiguity, iterate always, communicate intent). |
| 02 | Research | Research is a weekly habit, not a phase. Luma Health medication reminder: zero bugs, 4% adoption, never spoke to a patient. Covers the seven research biases (Hawthorn, Availability, Incentives, Note-taking, Novice/Expert, Telescope, Primacy). |
| 03 | Analysis | Data doesn't speak for itself. Affinity mapping, the collect→sort→cluster→insight arc, HMW reframing. An insight is a deep truth from behaviour — not an observation, quote, or theme. |
| 04 | Strategy | Good design decisions are also good business decisions. Business Model Canvas, Value Proposition Canvas, Jobs to Be Done. |
| 05 | Product | Empowered teams own outcomes; feature teams own roadmaps. Product trio (PM + designer + tech lead), Opportunity Solution Trees, discovery/delivery in parallel. |
| 06 | DevEx & Product Intelligence | Internal tools are real products. Documentation = UX, API design = IA, error messages = conversation. Product intelligence loop: data → insight → hypothesis → experiment → decision. |
| 07 | Service Design | Most experiences fail in the back stage, not the front. Integrated with the Service Blueprinting pack — five lanes, three lines (line of interaction, visibility, internal interaction). |
| 08 | Information Architecture | Structure is invisible until it breaks. Classical IA (card sorting, tree testing) plus **agent-era IA** — designing for delegation, not navigation (visibility, interruption, trust). |
| 09 | Conversational UI | When there's no button to press, language is the design. Dialogue design principles, persona design, disclosure in high-stakes contexts. |
| 10 | AI-Era Design | AI changes what designers build. It doesn't change why. Transparency spectrum, confidence UI, trust patterns, AI→human handoff moments, ethical design (bias, accessibility, incomplete data). |
| 11 | Data & Decisions | Leaders don't need more data, they need to trust the data they have. Dashboard design (hierarchy, primary metric, anomaly detection), data quality as UX. |
| 12 | Judgment in Practice | Tools matter. Judgment decides. Four forces shaping judgment (incentives, evidence, emotion, power), decision hygiene, judgment traps (premature convergence, overconfidence, consensus theatre, analysis paralysis). |
| 13 | Capstone / Integration | Integration is the real skill. Introduces **the Design-Led Loop** (Frame → Learn → Make sense → Decide → Design → Test → Integrate → Repeat) — a separate framework from the Frankly Human Loop, see `frankly-human-loop.md`. |

## Canonical scenario organisations

Meridian Bank (retail bank — modules 01, 04, 07, 10, 11), Luma Health (digital health — 02, 03, 09), Cargo (B2B logistics SaaS — 05), Orbit (consumer streaming — 08), Foundry (internal platform team — 06, 08, 12). Always name the org, always concrete numeric failure, never an individual's fault. See `brand-voice.md`.

## Voice notes specific to this curriculum

- "Warm clarity with a backbone. Grounded. Human. Commercially fluent. Emotionally intelligent." Same anchor as the brand overall, DESIGN-LED's baseline register (see `positioning.md`).
- Every module follows the same beat structure: OPEN (story) → CONTEXT → CONCEPT(s) → QUICK HIT (a debrief-style question) → ACTIVITY → CLOSE (one takeaway, one open question, next module named).
- "Participants Leave Able To" bullets are observable, specific skills, never generic ("gain valuable insights").
